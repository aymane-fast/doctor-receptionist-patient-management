Documentation de la base de donnees

Ce document presente la structure de la base de donnees du projet Laravel en se basant exclusivement sur les fichiers de migration du dossier database/migrations. Il decrit les tables, les colonnes, les contraintes, les relations detectees et fournit deux diagrammes Mermaid pour faciliter l'analyse et la capture en screenshot.

Introduction Tables Relations MCD / ERD UML

1. Introduction

L'objectif de cette page est de presenter la structure logique de la base de donnees du projet. La lecture a ete faite uniquement a partir des migrations, sans executer php artisan migrate et sans interroger une base reelle. Le schema ci-dessous correspond donc a l'etat attendu apres l'application cumulative des migrations dans l'ordre chronologique.

Source de verite utilisee

Uniquement les fichiers de migration Laravel du projet. Les relations listees ici proviennent des cles etrangeres declarees dans les migrations. Aucune relation supplementaire n'a ete inventee.

PK = cle primaire FK = cle etrangere UQ = unique nullable default index timestamps

2. Tables de la base de donnees

Chaque table ci-dessous est documentee avec ses colonnes, son type de donnees, les contraintes detectees dans les migrations et une courte description fonctionnelle.

3. Relations entre les tables

Les relations suivantes sont deduites uniquement des cles etrangeres explicites declarees dans les migrations. Les colonnes simplement indexees mais non contraintes par constrained() ne sont pas considerees comme des relations basees sur une cle etrangere.

Lecture metier en francais simple

    La colonne sessions.user_id est bien de type foreignId, mais la migration ne declare pas de contrainte de cle etrangere. Elle n'est donc pas ajoutee a la liste des relations formelles.
